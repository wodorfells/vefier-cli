# VeFier CLI 🚀

![demo](https://raw.githubusercontent.com/vefier/vefier-cli/main/assets/demo.gif)

Личный УНИВЕРСАЛЬНЫЙ AI-агент для терминала (TUI) с невероятно красивым интерфейсом и поддержкой **абсолютно любых** провайдеров. 

Написан на Go, запускается за 20 мс, работает на всех ОС.

## ✨ Ключевые возможности

1. **40+ Провайдеров "из коробки"**: OpenAI, Anthropic, Gemini, Ollama, OpenRouter, Mistral, xAI и другие. Вставил ключ — провайдер определился автоматически.
2. **Абсолютный контроль ключей**: Массовая проверка, ротация при 429/401, импорт из `.env`.
3. **Мощный Агент**: Поддержка MCP-серверов (Model Context Protocol), LSP, локальные сессии.
4. **Сравнение моделей**: Отправка одного промпта в 2–4 модели параллельно (A/B тест).
5. **Красота**: 15+ встроенных тем (Crush, Matrix, Dracula...), живое переключение `Ctrl+T`.

## 📦 Установка (за 30 секунд!)

### Windows
```powershell
winget install vefier
# или
scoop install vefier
```

### macOS
```bash
brew install vefier/tap/vefier
```

### Linux (Shell)
```bash
curl -fsSL https://vefier.com/install.sh | sh
```

### Из исходников (Go)
```bash
go install github.com/vefier/vefier-cli@latest
```

## 🚀 Быстрый старт

1. Запустите `vefier` в терминале.
2. Вставьте первый API-ключ (он автоматически определит формат: `sk-ant-*` -> Anthropic и т.д.).
3. Нажмите `Enter` и начинайте общаться.
4. Нажмите `Ctrl+K` для вызова меню инструментов (Менеджер ключей, MCP, Сравнение).
